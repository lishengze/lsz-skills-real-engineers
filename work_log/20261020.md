### 经验教训
1. **Windows 运行 bash 脚本选对 shell**：w64devkit 的 bash（`C:\dev\cplus\w64devkit\bin\bash.exe`）以 POSIX 模式解析，对数组 `FILES=()` 报 `syntax error: unexpected "("`；须用完整 bash（Git Bash `C:\Program Files\Git\bin\bash.exe`）。现象 → 根因（shell 能力差异）→ 解法（换 Git Bash）。
2. **bash 脚本须 LF 换行**：CRLF 会让 `$()` 等语法解析失败（`line 63: syntax error: unexpected "("`，`\r` 干扰）；转换后即可。验证脚本语法可先 `bash -n`。
3. **复盘脚本与 work_log 标题格式强耦合**：脚本靠 `## 任务`/`### 经验教训`/`### 待验证假设` 等固定标题聚合，日志须严格沿用 task_rule.md §11.1 模板，否则抓不到内容。
