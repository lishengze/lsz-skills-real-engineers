## 任务：排查并解决 Workspace 云桌面黑屏（22.04 捆绑 GStreamer 解码链缺 libva/fftw3）
**时间**：09:00-10:00

### 工作内容
1. **诊断**：系统 22.04.5 + Workspace E2004H07，VdSession 进程在跑、连接成功，但黑屏。`gst-inspect-1.0 avdec_h264` 报无此插件。
2. **判定用哪套 GStreamer**：`start.sh` 设 `GST_PLUGIN_PATH=RUN/gstreamer-1.0` → 捆绑 GStreamer 1.14.5，非系统。装系统插件无效。
3. **复现定位**：用 VdSession 完整 LD_LIBRARY_PATH 跑 `ctypes.CDLL('gstreamer-1.0/libgstlibav.so', RTLD_NOW)` 报 `libva.so.2: cannot open shared object file`。
4. **深入依赖链**：捆绑 libgstlibav/libgstvaapi 依赖核心 `libva.so.2`，但捆绑目录无（只有 x11/drm/wayland 变体）、系统 22.04 未装 libva；捆绑 libva-x11 需 `va_fool_postp`（数据符号，捆绑/系统都无定义）。装 libva 后暴露 `libfftw3.so.3`（双精度 FFTW）缺失，系统只有单精度。
5. **修复**：① 装系统 libva2 全套（libva2/libva-x11-2/libva-drm2/libva-wayland2）② 禁用捆绑 libva-x11（.bak）③ 装 libfftw3-double3 ④ 删 GStreamer 注册表缓存 ⑤ 干净环境重启 run.sh。
6. **验证**：`ctypes.CDLL('libgstlibav.so')` 加载 OK；捆绑 GStreamer 下 `gst_element_factory_make('avdec_h264')` 返回 OK；Workspace 重启后稳定运行，日志无 GStreamer 解码错误。
7. **沉淀**：更新知识库 `10` §8.5 + MEMORY.md 索引 + Prompt.md；追加 online_bug_log.md。

### 结论
- 根因 = VdSession 用捆绑 GStreamer 1.14，其解码插件 libgstlibav.so（avdec_h264）依赖 libva.so.2 + libfftw3.so.3，捆绑缺核心 libva.so.2、系统 22.04 未装 libva（且只装单精度 fftw3）→ 插件加载失败 → avdec_h264 创建失败 → 黑屏。
- 修复已就位并验证 avdec_h264 可用，Workspace 稳定运行。待用户重新登录连接实测确认画面正常。

### 经验教训
1. **云桌面黑屏先确认用哪套 GStreamer**（GST_PLUGIN_PATH 指向捆绑还是系统）：捆绑 GStreamer 时装系统插件无效，须修捆绑解码链依赖。22.04 未必是装系统插件（§1），也可能是捆绑链问题（§8 类）。
2. **捆绑解码插件依赖链**：libgstlibav.so（旧 FFmpeg，RUN 有）→ libva.so.2（核心，捆绑缺、系统缺）→ 装系统 libva；捆绑 libva-x11 需 va_fool_postp（系统 libva 无）→ 禁用捆绑用系统配套。
3. **libva.so.2 是核心库**，捆绑目录常只有 x11/drm/wayland 变体而缺核心，需系统提供。
4. **FFTW 有单双精度之分**：libfftw3f.so.3（单，libfftw3-single3）vs libfftw3.so.3（双，libfftw3-double3），缺哪个装对应包。
5. **ctypes.CDLL + RTLD_NOW 复现插件加载**比猜更准，能逐个暴露缺失库。
