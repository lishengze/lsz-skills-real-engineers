# 07 脚本与工具链（Scripts & Infrastructure）

> 本仓库的辅助脚本与基础设施配置。

## 1. 脚本

| 脚本 | 语言 | 作用 |
|------|------|------|
| `scripts/link-skills.sh` | bash | 把仓库中所有非 deprecated/misc 的技能软链到 `~/.claude/skills` 和 `~/.agents/skills`，`git pull` 后自动更新。仅供仓库维护者使用（dev-only）。 |
| `scripts/list-skills.sh` | bash | 列出仓库中所有 `SKILL.md` 文件（排除 node_modules），按路径排序。 |
| `scripts/sync-plugin-version.mjs` | Node.js | 把 `package.json` 的 `version` 同步到 `.claude-plugin/plugin.json`。`npm run version` 时自动执行。`--check` 模式只校验不修改。 |

## 2. `.claude-plugin/` 目录

| 文件 | 作用 |
|------|------|
| `plugin.json` | Claude Code 插件清单。含版本（1.3.1）、描述、27 个推广技能路径。 |
| `marketplace.json` | 本仓库的 marketplace 登记，供 Codex/Copilot/VS Code 等非 Claude Code 的 agent 发现和安装。 |

## 3. `.agents/` 目录

| 文件 | 作用 |
|------|------|
| `invocation.md` | user-invoked vs model-invoked 分类规范 + 技能间依赖约定 |
| `writing-docs.md` | docs 页写作规范（结构/约定/完成标准） |
| `install-block.md` | 安装命令的权威来源（README/docs 必须引用此处的措辞） |
| `adr/` | 架构决策记录（当前为空） |

## 4. 版本同步机制

```
package.json 版本（源）
  │  npm run version（changeset version → sync-plugin-version.mjs）
  ▼
plugin.json 版本（同步）
  │  npm run check-plugin-version（校验）
  ▼
两处一致
```

- `npm run version` = `changeset version && node scripts/sync-plugin-version.mjs`
- `npm run check-plugin-version` = `node scripts/sync-plugin-version.mjs --check`
- 发布工作流运行 `npm run version`，用户在"chore: version skills" PR 合并时获得新版本。

## 5. 常见坑

1. **link-skills.sh 的目标目录是软链指向本仓库时**：脚本会检测并报错退出，防止污染工作副本。
2. **plugin.json 与 package.json 版本不一致**：`check-plugin-version` 会退出 1，必须手动同步。
3. **misc/deprecated 技能被 link-skills.sh 链入**：脚本已排除 `-not -path '*/deprecated/*' -not -path '*/misc/*'`，不会链入。
