# 05 其他分桶技能（Misc / In-Progress / Deprecated）

> 非推广分桶，不进插件、不进顶层 README、无 docs 页。

## 1. Misc（保留但少用）

`skills/misc/`，不推广，冻结且不维护。

| 技能 | 作用 |
|------|------|
| **git-guardrails-claude-code** | 为 Claude Code 设置钩子，拦截危险 git 命令（push/reset --hard/clean 等） |
| **migrate-to-shoehorn** | 把测试文件从 `as` 类型断言迁移到 `@total-typescript/shoehorn` |
| **scaffold-exercises** | 创建练习目录结构（sections/problems/solutions/explainers） |
| **setup-pre-commit** | 设置 Husky pre-commit 钩子（lint-staged + Prettier + 类型检查 + 测试） |

## 2. In-Progress（beta，公开求反馈）

`skills/in-progress/`，公开但未进插件，可随时变更或消失。

| 技能 | 调用方式 | 作用 |
|------|---------|------|
| **loop-me** | User-invoked | 跨多会话拷问自己，产出可执行工作流 spec，用当前目录作有状态工作区 |
| **writing-beats** | 未明确 | 把文章塑造成"节拍"旅程，选起始节拍写一节，再转下一节直到自然结束 |
| **writing-fragments** | 未明确 | 拷问会话挖掘碎片（异质写作素材），追加到单一文档作为未来文章原材料 |
| **writing-shape** | 未明确 | 拿原始材料 markdown，逐段塑造成文章，每步讨论格式选择 |
| **claude-handoff** | User-invoked | 把当前会话交给新的后台 agent（通过 `claude --bg` 播种 handoff 摘要） |
| **setup-ts-deep-modules** | User-invoked | 把 dependency-cruiser 接入 TypeScript 仓库，使每个包为 deep module（实现藏于子文件夹，仅通过入口文件可达，测试通过入口测） |

安装方式：`npx skills@latest add mattpocock/skills --skill=<name>`

## 3. Deprecated（已弃用）

`skills/deprecated/`，已弃用，仅保留 README 说明。当前为空（仅有 `README.md`）。

## 4. 常见坑

1. **非推广技能被误当推广**：misc/in-progress/deprecated 的技能不登记在 plugin.json、README、docs 中，须用 `--skill=<name>` 单独安装。
2. **in-progress 技能可能消失**：beta 阶段，随时可变更或移除，无向后兼容保证。
