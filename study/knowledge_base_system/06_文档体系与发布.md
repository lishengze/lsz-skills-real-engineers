# 06 文档体系与发布（Docs & Publishing）

> 本仓库的文档体系分两层：技能文件（SKILL.md）与人类文档页（docs/），分别面向 agent 和人类。

## 1. 文档体系结构

```
SKILL.md（技能本体，agent 读）
  ↓ 提炼/镜像
docs/<bucket>/<name>.md（人类文档页，发布到 aihero.dev）
```

- **SKILL.md**：技能本体，含前件（description/invocation mode）和步骤。agent 执行时读它。
- **docs 页**：人类文档，帮人记住"何时该用这个技能"（认知负载缓解）。**不是 SKILL.md 的副本**。

## 2. 哪些技能有 docs 页

- ✅ `engineering/`、`productivity/`（推广分桶）— **必须**有。
- ❌ `misc/`、`in-progress/`、`deprecated/` — 无 docs 页。
- 技能从非推广分桶移入推广分桶 → **新增** docs 页；反向移动 → **删除**。
- 推广技能被彻底移除 → docs 页保留为**归档页**（加 blockquote 注明移除版本和替代品）。

## 3. docs 页结构（固定框架）

每页按固定顺序包含：
1. **## What it does**：一句话工作 + **定义约束**（让该技能与众不同的关键事实），以散文句书写，不用"关键事项："标注。
2. **## When to reach for it**：调用方式（你输入/模型自动触发）+ 触发边界。
3. **## Prerequisites**（可选）：仅当技能需要前置条件时出现。
4. **<自由形式中间节>**：1~3 节，用技能自己的词汇，必须露出**引导词**。
5. **## Common questions**：真实用户问过的问题（从 wiki/issues/changelog 搜集），按频率排序。
6. **## It's working if**：可验证的标志（不打开 SKILL.md 就能检查）。
7. **## Where it fits**：角色（链步骤/一次性设置/定期维护/随时独立）+ 邻接技能 + 指向 `ask-matt`。

## 4. 文档页写作规范

- **所有链接是绝对链接**（`https://aihero.dev/skills-<name>` 或 `https://github.com/...`），因发布到 aihero.dev 后相对链接会断。
- 无 H1（发布页从 slug 取标题）。
- 无安装命令（ai-hero 页面模板在正文上方渲染安装 widget）。
- 无作者引用（"Matt says" 等去掉，保留用户引用如"one user reported…"）。
- 用 AI Coding Dictionary 词汇（`context window`/`subagent`/`harness`/`primary source`/`agent mode`），首次出现链接到 `https://www.aihero.dev/ai-coding-dictionary/<slug>`。
- 分支用表格或列表，不用段落。
- 页面保持低认知负载。

## 5. 发布机制

- 发布 URL：`https://aihero.dev/skills-<name>`（恒为 `skills-<name>`，不分桶）。
- 维护触发：新增/改名/改行为 → 同步 docs 页。
- `ask-matt` 路由器也需同步：新增/改名/移除用户可触达技能时更新。

## 6. 安装路由

| Agent | 安装方式 | 自动更新 |
|-------|---------|:-------:|
| Claude Code | `claude plugin install mattpocock-skills@claude-plugins-official` | ✅ 默认 |
| Codex | `codex plugin marketplace add mattpocock/skills` + `add` | ✅ 启动时 |
| Copilot CLI | `copilot plugin marketplace add ...` + `install` + settings.json 配 `autoUpdate: true` | ✅ |
| VS Code | Chat: Install Plugin From Source | ✅ 每日 |
| Gemini CLI | `gemini skills install https://github.com/mattpocock/skills.git --path skills/engineering` | ❌ 手动 |
| 其他 | `npx skills@latest add mattpocock/skills -a <agent>` | ❌ 手动 |

**两种路由互斥**：插件（managed bundle）vs skills.sh（可编辑文件），同时安装会每个技能出现两次，必须"二选一"。

## 7. 常见坑

1. **docs 页用相对链接**：发布到 aihero.dev 后全断，必须用绝对链接。
2. **docs 页写安装命令**：ai-hero 已渲染 install widget，页内再写会重复且漂移。
3. **技能改名/移桶未同步 docs 页**：路径和 URL 都需更新。
4. **docs 页变成 SKILL.md 副本**：页面的作用是"帮人决定何时用"，不是"告诉 agent 怎么做"。
