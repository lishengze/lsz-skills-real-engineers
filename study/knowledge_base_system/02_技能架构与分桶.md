# 02 技能架构与分桶（Skills Architecture）

> 本仓库是 agent 技能集合，理解"分桶"与"调用方式"是使用全部技能的前提。

## 1. 分桶（Bucket）

| 分桶 | 目录 | 定位 | 是否推广（进插件/README/docs） |
|------|------|------|:---:|
| **engineering** | `skills/engineering/` | 每日代码工作 | ✅ |
| **productivity** | `skills/productivity/` | 通用非代码工作流 | ✅ |
| **misc** | `skills/misc/` | 保留但少用，不推广 | ❌ |
| **in-progress** | `skills/in-progress/` | beta，公开求反馈，未进插件 | ❌ |
| **deprecated** | `skills/deprecated/` | 已弃用 | ❌ |

- 推广分桶（engineering/productivity）的技能须：顶层 README 有引用 + plugin.json `skills` 数组有登记 + 有 `docs/<bucket>/<name>.md` 文档页。
- 非推广分桶（misc/in-progress/deprecated）三处都不出现，也无 docs 页。

## 2. 调用方式（Invocation）— 最核心分类轴

每个 `SKILL.md` 按**谁能触达**分为两类（详见 `.agents/invocation.md`）：

| 类型 | 谁能触达 | 配置 | description 面向 | 典型 |
|------|---------|------|-----------------|------|
| **User-invoked** | 仅人类输入其名字 | `disable-model-invocation: true` + `policy.allow_implicit_invocation: false` | 人类（一行摘要，去掉触发词） | `ask-matt`/`grill-me`/`triage`/`retro` 等 |
| **Model-invoked** | 模型或用户 | 默认（省略上述配置） | 模型（保留丰富触发短语） | `grilling`/`code-review`/`tdd`/`diagnosing-bugs` 等 |

**关键不变量**：
- user-invoked 技能**只能被人类触发**，任何其他技能都不能调用它（包括通过 Skill tool 点名）。
- user-invoked 技能可以调用 model-invoked 技能，但绝不能触达另一个 user-invoked 技能。
- 每个技能旁都有 `agents/openai.yaml`（Codex UI 元数据），与 `SKILL.md` 前件保持同步——"两个 harness 要么都是 user-invoked，要么都不是"。

## 3. 技能间依赖约定

- 依赖用**显式指令**表达：`Call the Skill tool with "grilling"`，而非 `../other-skill/FILE.md` 深层交叉引用，也非裸 `/skill` 提及。
- Skill tool **每次一个技能**；需要两个技能就写两次调用（"Call the Skill tool twice, for X and Y"），不写"with X and Y"。
- 该约定**仅适用于 model-invoked 技能**。若前置条件是 user-invoked 技能（如 `setup-matt-pocock-skills`），应写成"告诉用户运行 `/setup-matt-pocock-skills`"，绝不作 Skill tool 调用。
- 路由器散文（`ask-matt`、分桶 README）只是给人选技能，不算调用，保留 `/skill` 风格标签。

## 4. 主动 vs 被动领域工作

- 仅**阅读** `GLOSSARY.md` 取词 = 一行散文指针，不是 `domain-modeling` 技能。
- 只有**主动构建/打磨**领域模型（挑战术语、边界场景、写 ADR、内联更新 GLOSSARY.md）才是 `domain-modeling`。

## 6. 常见坑

1. **user-invoked 技能被 Skill tool 调用**：违反不变量。前置条件是 user-invoked 时，改为指导人类运行。
2. **两个 harness 配置不同步**：一个 user-invoked 技能只在 Claude Code 禁了、Codex 没禁，会漏。
3. **裸 `/skill` 提及当调用**：命中率低，应写成 `Call the Skill tool with "name"`。
