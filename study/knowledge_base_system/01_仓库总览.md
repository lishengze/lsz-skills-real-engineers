# 01 仓库总览（lsz-skills-real-engineers）

> 本仓库是 **Matt Pocock 的 agent 技能库**（Skills For Real Engineers），用于"真实工程"而非"vibe coding"。本知识库系统化记录其结构、技能、规范与使用方式。

## 1. 是什么 / 定位

- 名称：**mattpocock-skills**（`package.json` name），版本 **1.3.1**。
- 一句话：一套**可插拔、易适配、可组合**的 agent 技能集，任何模型都可用，基于数十年工程经验提炼。
- 核心理念：通过小型、聚焦的技能修复 agent 的常见失败模式，而非用 GSD/BMAD/Spec-Kit 之类"接管流程"的重型框架（那些会夺走控制权并让流程 bug 难排查）。
- 作者 Matt Pocock（aihero.dev），仓库 `https://github.com/mattpocock/skills`，MIT 协议。

## 4. 版本与发布

- `npm run version` = `changeset version && node scripts/sync-plugin-version.mjs`（把 package.json 版本同步到 plugin.json）。
- `npm run check-plugin-version` = `node scripts/sync-plugin-version.mjs --check`（校验两处版本一致，不一致退出 1）。
- 安装路由（见 `.agents/install-block.md`）：Claude Code 用官方 marketplace；Codex/Copilot 用本仓库 marketplace；Gemini 用 `gemini skills install`；其他用 skills.sh。

## 5. 关键约定（CLAUDE.md 提炼）

- 只有 `engineering/`、`productivity/`（推广分桶）技能需在顶层 README 和 plugin.json 中登记；`misc/in-progress/deprecated` 不登记。
- 推广技能必须有 `docs/<bucket>/<name>.md` 文档页（发布 URL 恒为 `https://aihero.dev/skills-<name>`）。
- 每个 `SKILL.md` 要么 user-invoked（`disable-model-invocation: true` + `policy.allow_implicit_invocation: false`），要么 model-invoked。
- `ask-matt` 是路由器，新增/改名/移除用户可触达技能时须同步更新它。
- `scripts/link-skills.sh` 把非 deprecated/misc 技能软链到 `~/.claude/skills`、`~/.agents/skills`。
- **仓库正文禁止 em-dash**（`SKILL.md`/docs/README/CHANGELOG/ADR/changesets/注释），用逗号/冒号/句号/括号/连词改写，禁止盲替字符。

## 6. 常见坑

1. **版本不同步**：package.json 与 plugin.json 版本须一致，用 `npm run check-plugin-version` 校验。
2. **user-invoked 技能被模型误触达**：须同时在 Claude Code 前件 `disable-model-invocation: true` 和 `agents/openai.yaml` 的 `policy.allow_implicit_invocation: false` 设置，两个 harness 要同步。
3. **docs 页与技能不同步**：工程/生产力技能改名/改行为时须同步 docs 页；`misc/in-progress/deprecated` 无 docs 页。
4. **em-dash 回潮**：编辑时勿插入——（长破折号）。
