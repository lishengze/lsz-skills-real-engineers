# 04 生产力技能详解（Productivity Skills）

> 通用非代码工作流技能，位于 `skills/productivity/`，共 7 个（推广）。

## 1. User-invoked（人类触发）

| 技能 | 作用 | 触发场景 |
|------|------|---------|
| **grill-me** | 被无限拷问计划/设计，直到决策树每个分支解决 | 非代码用途的对齐拷问（grill-with-docs 的无 docs 版） |
| **handoff** | 把当前对话压成 handoff 文档，供另一个 agent 继续 | 交接给其他 agent/会话 |
| **teach** | 跨多会话教用户新技能/概念，用当前目录作有状态教学工作区 | 分多次教学 |
| **to-questionnaire** | 把无法独自回答的决策变成 Markdown 问卷，给能回答的那个人（异步或会议中） | 需要特定人拍板的决策 |
| **wait-what** | 消息没落地时触发，用 GLOSSARY.md 词汇重新用大白话解释 | 对方没听懂 |

## 2. Model-invoked（模型或用户触发）

| 技能 | 作用 | 触发场景 |
|------|------|---------|
| **grilling** | 对计划/决策无限拷问直到决策树全解决。是 grill-me/grill-with-docs/triage/wayfinder/improve-codebase-architecture 背后的可复用拷问原语 | 需要深入拷问 |
| **writing-for-agents** | 为 agent 写文档：技能、AGENTS.md/CLAUDE.md、任何 agent 经指针触达的文档 | 写/编辑技能或 agent 文档 |

## 3. grilling 原语（最核心）

`grilling` 是**可复用的拷问原语**，被多个用户级技能复用：
- `grill-me`（非代码）
- `grill-with-docs`（+ 领域建模）
- `triage`、`wayfinder`、`improve-codebase-architecture`（工程流程内嵌）

**拷问循环**：连续问题间用 `---` 分隔（而非连在一起），直到决策树每个分支都解决。

## 4. writing-for-agents 要点（文档写作规范）

为 agent 写文档的纪律（详见本仓库 `.agents/writing-docs.md` 与技能自身）：
- **Context Pointer**：指针措辞决定 agent 何时触及材料，写清"材料是什么 + 触发分支"。
- **信息层次**：步骤内联、参考按需查阅、细枝末节放指针后（渐进披露）。
- **引导词（Leading Word）**：用预训练已有的紧凑概念锚定行为。
- **正向引导，少用否定**：禁止指令会把禁止行为拖入上下文。
- **单一事实来源**：每个含义只在一个权威位置；环境能查到的不要复述。
- **每行检查相关性**：删 no-op 指令与过时内容。

## 5. 常见坑

1. **grill-me 与 grilling 混淆**：grill-me 是用户级技能（人类触发），grilling 是模型级原语（可被其他技能调用）。
2. **writing-for-agents 写成给人看**：agent 文档要"指针+触发分支"，不是流水账；无 no-op 指令。
3. **handoff 交接不完整**：应压缩到关键上下文、当前状态、下一步，供新 agent 无缝接手。
